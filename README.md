# Coursely (Toxa) — Premier Online Learning Platform UI

An executive EdTech web platform UI designed for tech professionals and ambitious learners, featuring interactive course tracks, real-time salary ROI calculator, syllabus inspection modals, and mentor faculty spotlights.

## ✨ Features
- **Silicon Valley EdTech Aesthetic**: Electric indigo, cyan glow, dark space backdrop with Outfit and Plus Jakarta Sans typography.
- **Interactive Career ROI Calculator**: Calculates estimated annual salary lift and timeline across AI Engineering, UI/UX Systems, and Cloud Architecture.
- **Dynamic Course Filtering & Live Search**: Filter tracks by category with instant card filtering and keyword search.
- **Interactive Syllabus Inspector**: Inspect detailed 4-module breakdown for every professional track.
- **Mentor Profiles & Verifiable Credential Previews**: Cryptographic certificate showcase with one-click LinkedIn integration mockups.
